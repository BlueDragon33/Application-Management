# Prepared Russian pronunciation

These MP3s were synthesized offline from the course text using RHVoice 1.14.0 and the Aleksandr-HQ Russian voice at 24 kHz. They were gain-adjusted and encoded as mono MP3. The exact source text is listed in the course's prepared-audio.ts.

The voice is based on recordings of Aleksander Karlov and was created by Artem Plaksin, Sergey Parshakov, Beka Gozalishvili, and Zvonimir Stanecic. The voice source is [RHVoice Aleksandr-HQ](https://github.com/RHVoice/aleksandr-hq-rus). The prepared MP3s are available under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

The course credits speaker recordings separately. This directory does not contain voice models or runtime dependencies.
